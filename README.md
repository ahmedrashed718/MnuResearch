# MNU Student Research & Innovation Conference

Foundation for the conference web application, built with React, Vite, React Router, and Tailwind CSS.

## Getting started

1. Copy `.env.example` to `.env` and set `VITE_API_URL` for the backend.
2. Install dependencies with `npm install`.
3. Start development with `npm run dev`.
4. Create a production build with `npm run build`.

The routed pages are intentionally minimal. Shared UI, layouts, API handling, and the route registry are ready for feature development.
